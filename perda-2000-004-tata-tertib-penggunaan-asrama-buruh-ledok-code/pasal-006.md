# Pasal 6
(1) Kepada setiap penghuni Asrama Buruh Ledok Code diwajibkan membayar Retribusi yang besarnya diatur dengan Peraturan Daerah tersendiri.
(2) Penghuni diwajibkan memelihara kebaikan dankebersihan bangunan maupun tanahnya serta lingkungannya.
(3) Penghuni diwajibkan memelihara keamanan, ketertiban dan ketentraman baik di dalam maupun di luar kompleks Asrama Buruh Ledok Code.
